# Oven SMP client pack

Minecraft 1.21.1 / NeoForge 21.1.266. The `mods/` directory contains the pinned client set; `config/` carries the matching ModernFix compatibility settings. The launcher obtains the manifest from Oven API and verifies each file by SHA-256 before installing it.

The exact versions, upstream project links, licenses, and local changes to Create Deco and Create: The Air War are recorded in `.github/pack-provenance/candidate.json` and `CANDIDATE-NOTES.md`. The two local variants retain their original download URLs and hashes in that manifest. Server-only optimization tools are in the private `oven-game` repository.
